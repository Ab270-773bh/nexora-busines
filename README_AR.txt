WILD HUNT ONLINE — النسخة المتكاملة الأولية
============================================

المتطلبات:
- Godot 4.7.2 Stable (Standard) أو إصدار Godot 4.x متوافق.
- المشروع يستخدم GDScript ولا يحتاج إضافات خارجية.

طريقة التشغيل:
1) فك ضغط ملف ZIP.
2) افتح Godot.
3) اختر Import / استيراد.
4) افتح مجلد WILD_HUNT_ONLINE_COMPLETE.
5) اختر project.godot ثم Import.
6) اضغط تشغيل ▶.

الموجود داخل النسخة:
- عالم ثلاثي الأبعاد: أرض عشبية، أشجار، صخور، بحيرة ومخيم.
- شخصية لاعب قابلة للحركة من أزرار الشاشة أو WASD والأسهم.
- كاميرا منظور ثالث قابلة للدوران بالسحب على الشاشة.
- غزلان وطيور داخل العالم.
- إطلاق صيد افتراضي وجمع HUNT COINS.
- متجر وشراء ذخيرة.
- مهمات ومكافآت.
- كلب صيد مع نظام مستويات تدريب وصفارة.
- تطوير المخيم.
- حفظ العملات والذخيرة والتقدم محلياً.

ملاحظات مهمة وصريحة:
- هذه نسخة Prototype متكاملة للأنظمة الأساسية وقابلة للتشغيل والتجربة، وليست لعبة AAA بمستوى PUBG.
- الصيد هنا ميكانيكية لعب خيالية داخل اللعبة فقط.
- لا يوجد حالياً اتصال إنترنت أو Multiplayer حقيقي أو حسابات وخوادم.
- الرسومات مبنية بأشكال ثلاثية الأبعاد أساسية؛ يمكن استبدالها لاحقاً بنماذج احترافية.
- لا توجد مشتريات أو أموال حقيقية؛ العملات داخل اللعبة فقط.

التحكم:
- أزرار الاتجاهات على الشاشة أو WASD / الأسهم.
- اسحب الجهة اليمنى من الشاشة لتدوير الكاميرا.
- زر إطلاق للصيد.
- المتجر / الكلب / المخيم / مهمة / صفارة.
